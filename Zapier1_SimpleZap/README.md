# Zapier1 Simple Zap


## Project
Create a basic zap with two steps.

## Tools
- Zapier
- Google Forms
- Google Email

## Tasks
- Create a form using Google Forms
- Publish the Google Form
- 
- Create a new Zap
    - Trigger: Google Forms
        - Google Form Sample Form 1
    - Action: Google Email
        - Send an email with information from the form
- Name the Zap
- Publish the Zap
- Copy Google Form Responder link and paste in a new tab
- Complete the Google Form Sample Form 1 and click Submit
- Check Google Email
